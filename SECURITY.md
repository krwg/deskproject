# Security Policy

## Supported versions

Only the latest `main` branch of this site is maintained.

## Reporting a vulnerability

Please **do not** open a public issue for security-sensitive reports.

Email the maintainer via the contact methods on [krwg.github.io/krwg](https://krwg.github.io/krwg/), or open a **private** security advisory on GitHub if available for this repository.

Include:

- a short description of the issue
- steps to reproduce
- impact (XSS, token leak, dependency CVE, etc.)

You should get an acknowledgement when the report is received. Fixes for confirmed issues are shipped on `main` / GitHub Pages as soon as practical.
