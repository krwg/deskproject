# Куда класть фото и видео

> **Важно:** после добавления файлов запусти:
>
> ```powershell
> npm.cmd run images
> ```
>
> Без этого сайт не увидит новые фото.

## Сеты (галерея / evolution / current setup)

```
public/images/sets/01 … 60/
```

Папки **01–60 уже созданы**. Новые сеты появляются на сайте **автоматически** после `npm run images`.

### Хронология

```
01  = самый старый
…
60  = самый новый (когда дойдёшь)
```

- **Gallery / Evolution** — все сеты с файлами, слева старые → справа новые  
- **Current Setup (home)** — автоматически 4 самых новых сета  

### Файлы внутри папки

```
sets/12/
  main.jpg      ← обложка (или main.mp4 / main.png)
  02.jpg        ← уточнения — любое количество / любые имена
  03.mp4        ← видео (в UI — 5 сек таймлуп)
```

| Файл | Значение |
|------|----------|
| `main.*` | Обложка |
| остальные фото/видео | Открываются после клика по обложке |
| `*-thumb.webp` | Создаёт скрипт |

Поддерживаются: `.jpg` `.png` `.webp` `.mp4` `.webm` `.mov`

## Фон главной страницы

```
public/images/home/
  main.jpg   ← полноэкранный фон под заголовком и кнопками
```

Положи одно фото (лучше `main.jpg`). После `npm run images` оно станет фоном hero.  
Если папка пустая — временно берётся обложка самого нового сета.

## Опциональные названия сетов

Только если хочешь своё имя/дату — `src/data/sets.meta.ts`:

```ts
export const setsMetaOverrides = {
  '01': { title: 'First laptop', date: '2019' },
  '12': { title: 'Current desk', caption: 'RGB era' },
}
```

## Команды
